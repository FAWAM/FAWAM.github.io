# FAWAM GitHub Pages Outline

This folder is a static project-page scaffold inspired by the Genie Envisioner page structure:

1. Header navigation
2. Hero with paper title, author line, project links, and teaser figure
3. Abstract
4. Method overview with two main diagrams
5. Contact-rich task overview
6. Video results with task and mode selectors
7. Downloads
8. Citation

## Files To Edit First

- `index.html`: title, authors, abstract, download links, citation, section text
- `assets/css/styles.css`: colors, spacing, typography, responsive layout
- `assets/js/main.js`: video paths and task names

## Deployment Options

Option A: rename this folder to `docs` and set GitHub Pages to serve from `main / docs`.

Option B: copy the contents of this folder to the root of a repository named
`<username>.github.io`.

Option C: use this folder as a standalone branch/source for a project page such as
`https://<username>.github.io/FAWAM/`.
