# FAWAM Project Page

Static GitHub Pages scaffold for the FAWAM paper/project.

Open `index.html` directly in a browser to preview. No build step is required.

Main edit points:

- `index.html` for project content
- `assets/css/styles.css` for visual design
- `assets/js/main.js` for video switching

The page uses local assets only, so it should continue to work after being moved into a
GitHub Pages repository or `docs` folder.
